# ScreenFrame - 画面枠表示アプリ

Windows 11で画面に枠を表示する透明オーバーレイアプリケーションです。
配信や画面録画時に特定の範囲を強調表示するのに便利です。

## 機能

- **透明な枠表示**: 画面上に赤や他の色の枠を表示
- **クリックスルー**: 枠はマウスクリックを妨げません
- **常に最前面**: 枠は常に最前面に表示されます
- **カスタマイズ可能**: 位置、サイズ、色、太さを自由に設定
- **プリセット**: 720p、1080p、4:3、16:9などのプリセットサイズ
- **システムトレイ**: タスクバーから簡単にアクセス

## ビルド方法

### 必要環境
- .NET 6.0 SDK以上
- Windows 10/11

### ビルド手順

```bash
# リポジトリをクローン
git clone [repository-url]
cd StreamRange

# ビルド
dotnet build

# 実行
dotnet run
```

### リリースビルド

```bash
# リリースビルドの作成
dotnet publish -c Release -r win-x64 --self-contained
```

## 使い方

1. アプリケーションを起動すると、赤い枠が画面に表示されます
2. **Ctrl+Shift+F** を押すと設定画面が開きます
3. 設定画面で以下を調整できます：
   - 枠の位置（X, Y座標）
   - 枠のサイズ（幅、高さ）
   - 枠の太さ（1-20ピクセル）
   - 枠の色（赤、緑、青、黄、など）
4. **ESC** キーで設定モードを終了します
5. システムトレイアイコンから：
   - ダブルクリックで設定画面を開く
   - 右クリックでメニューを表示
   - 枠の表示/非表示を切り替え
   - アプリケーションを終了

## ショートカットキー

- **Ctrl+Shift+F**: 設定画面の表示/非表示
- **ESC**: 設定モードを終了

## プリセットサイズ

- **720p**: 1280×720
- **1080p**: 1920×1080
- **4:3**: 800×600
- **16:9**: 1600×900

## 注意事項

- 枠は常にクリックスルー状態で、マウス操作を妨げません
- 設定を変更する際は、一時的にクリックスルーが無効になります
- 枠は常に最前面に表示されるため、フルスクリーンアプリケーションの上にも表示されます
